플랫폼 원클릭 자동 발행 Hub

Google 로그인 또는 API 토큰으로 블로그에 즉시 자동 포스팅합니다.

Google Blogger 간편 연동: 보유하신 Blogger 블로그의 Blog ID(숫자)를 입력하면 즉시 발행 및 원하는 시간 예약 발행을 바로 실행할 수 있습니다.

구글 블로거 관리자 URL의 /blog/posts/[숫자ID] 부분입니다.

설정한 미래 시간에 맞춰 Google Blogger 서버에서 자동으로 글이 공개됩니다.

Google OAuth Playground 또는 Google Cloud에서 발급받은 Bearer Token

내 Blogger Blog ID 확인하는 방법
  1. Blogger 관리자(blogger.com)에 접속합니다.
  2. 주소창의 URL을 확인합니다: https://www.blogger.com/blog/posts/8932018239012389102
  3. /posts/ 뒤에 붙은 고유 숫자 전체를 복사하여 위 'Blogger Blog ID'에 입력하고 [설정 저장]을 누르세요.
스레드(Threads) 3~4부작 골든 타래 최적화: 긴 블로그 글을 스레드 알고리즘과 높은 도달률에 맞춰 3~4개의 고효율 타래(Thread)로 자동 요약 재구성합니다. 원하는 타래만 선택해 즉시 복사하거나 직접 수정할 수 있습니다.
선택됨: 4/4개
티스토리 Open API 자동 포스팅: 티스토리 오픈 API Access Token과 블로그 주소를 입력하면 즉시 새 글로 발행됩니다. API 가이드 보기 ↗

발급받은 개인 Access Token을 입력하세요 (브라우저 로컬에 안전하게 저장됩니다).

GitHub 정적 블로그(Jekyll/Hugo/Astro) 자동 커밋: GitHub Personal Access Token을 통해 저장소에 마크다운 포스트를 직접 커밋 및 배포합니다.
네이버 블로그 모바일/PC 100% 직접 자동 발행: 확장 프로그램 설치 없이 브라우저에 로그인된 네이버 세션(`m.blog.naver.com`)으로 포스팅 데이터를 직접 전송해 글을 1초 만에 자동 발행합니다.
