# ⚓ BLODOCK Auto Publisher (크롬/웨일 확장 프로그램)

BLODOCK(블독) AI 에디터에서 작성한 포스팅 콘텐츠를 **네이버 블로그, Threads, Blogger, 티스토리**에 원클릭으로 자동 입력해주는 크롬/웨일 전용 확장 프로그램입니다.

---

## 💻 **확장 프로그램 설치 방법 (크롬 / 네이버 웨일)**

### 1️⃣ **크롬(Chrome) 브라우저 설치 방법**
1. 크롬 주소창에 `chrome://extensions` 입력 후 엔터
2. 오른쪽 상단의 **[개발자 모드]** 스위치를 **켜기(ON)**로 변경
3. 왼쪽 상단의 **[압축해제된 확장 프로그램을 로드합니다]** 버튼 클릭
4. 이 프로젝트 폴더 내의 `extension` 폴더를 선택하면 설치 완료!

---

### 2️⃣ **네이버 웨일(Whale) 브라우저 설치 방법**
1. 웨일 주소창에 `whale://extensions` 입력 후 엔터
2. 오른쪽 상단의 **[개발자 모드]** 스위치를 **켜기(ON)**로 변경
3. 왼쪽 상단의 **[압축해제된 확장 프로그램 로드]** 버튼 클릭
4. 이 프로젝트 폴더 내의 `extension` 폴더를 선택하면 설치 완료!

---

## 🚀 **사용 방법**
1. [BLODOCK 웹 사이트](https://kukii0202.github.io/blog-anti/)에서 AI로 블로그 글 작성 후 **[발행하기]** 클릭
2. 네이버 블로그/Threads/Blogger/티스토리 이동 버튼을 누르면
3. 열린 에디터 화면 상단에 **🟢 BLODOCK 원클릭 자동 입력 완료!** 안내 배너가 뜨며 제목과 본문이 0.1초 만에 자동으로 쏙 채워집니다!
